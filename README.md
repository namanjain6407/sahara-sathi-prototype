## 📌 About the Project

**Sahara Sathi** is a user-friendly web application specially designed for **elderly people** to ensure their safety, health tracking, and daily engagement.

The main goal of this project is to provide **quick emergency support**, **health reminders**, and **accessible information** in a simple and intuitive interface.

---

## 💡 Key Features

### 🏥 Health Monitor

* Medicine reminder system
* To-do list for daily health tasks
* Voice assistance (Hindi + English)
* Smart alerts using AI-based reminders

---

### 📰 Smart News Section

* Latest news updates
* Multi-language support (Hindi & English)
* Voice-enabled news reading

---

### ▶️ YouTube Integration

* Direct access to YouTube for entertainment
* Simple navigation for elderly users

---

### 🚨 SOS Emergency System (Core Feature)

* Hold SOS button for 2 seconds
* Automatically:

  * 📞 Calls emergency contact
  * 📍 Sends live GPS location
* Designed for **instant help in critical situations**

---

## 🔐 Authentication System
